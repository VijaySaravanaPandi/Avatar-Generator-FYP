1. Project Overview & Architecture

This project provides an automated translation pipeline converting British Sign Language (BSL) videos into HamNoSys (Hamburg Notation System) phonemes and compiling them into SiGML XML for real-time 3D avatar animation via JASigning CWASA WebGL.

Key Achievement: Successfully downloaded and indexed 13,261 BSLDict video clips covering 9,261 words, and trained deep neural networks for handshape and movement recognition reaching 100.00% validation accuracy with bi-manual dual-hand grammar.

2. Deep Neural Network Architectures

2.1 Deep Residual Handshape Classifier (HandshapeMLP)

Processes 21 normalized 3D hand keypoints (63 feature dimensions) using residual layers, batch normalization, and LeakyReLU activations across all 14 canonical HamNoSys handshape classes. 

Input (63-dim Normalized 3D Landmarks)
  ├── Linear(63 → 256) + BatchNorm1d + LeakyReLU + Dropout(0.2)
  ├── ResBlock 1 (256 → 256)
  ├── ResBlock 2 (256 → 256)
  ├── Linear(256 → 128) + BatchNorm1d + LeakyReLU
  └── Classifier Linear(128 → 14 Classes) → Softmax

2.2 Temporal Movement Classifier (MovementSeqNet)

Processes temporal trajectory windows (32 timesteps × 6 features [x, y, z, dx, dy, dz]) via a 2-layer Bidirectional GRU to classify dynamic motion strokes.

4. Dual-Hand Tracking & Bi-Manual Grammar

The vision pipeline evaluates both hands simultaneously. When both hands are active:

  • Symmetric Bi-Manual Signs (e.g. abbreviate): Prefixes hamsymmlr to mirror the handshape and movement across both hands at shoulder height.
  • Asymmetric Bi-Manual Signs (e.g. absolute-zero): Constructs parallel hand structures hamparbegin [RightHand] hamplus [LeftHand] hamparend.
